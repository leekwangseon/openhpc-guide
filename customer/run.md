# 계산 실행과 결과 확인

담당자에게 안내받은 실행 방식을 사용하세요. 직접 실행하는 환경은 첫 번째 절을, Slurm을 사용하는 환경은 두 번째 절을 확인합니다.

## 직접 실행
이 절차는 **스케줄러를 통하지 않는 실행이 허용되고 노드 직접 접속 권한이 제공된 경우**에만 적용합니다. ANSYS 등 제품 자체의 원격 실행 도구를 사용하는 현장은 제품별 안내를 우선합니다.

### 실행 전

관리자 또는 예약 체계에서 사용할 노드·CPU·메모리·종료 시각을 확인합니다. 아래 명령은 상황을 보는 보조 수단이며 예약이나 자원 점유권을 보장하지 않습니다.

```bash
ssh YOUR_APPROVED_NODE
hostname
uptime
free -h
ps -u "$USER" -o pid,etime,%cpu,%mem,args
```

`w`는 로그인 세션을 보여줄 뿐, 모든 계산 작업을 보여주지는 않습니다. 다른 사람이 로그인하지 않았어도 계산 중일 수 있습니다. GPU 확인 명령은 해당 GPU와 도구가 설치된 노드에서만 사용합니다.

### 계산 시작

지정한 공유 작업 폴더에서 제품별 안내 명령으로 실행합니다. 다음은 문법 설명용이며 실제 실행 명령이 아닙니다.

```bash
YOUR_APPLICATION YOUR_CONFIRMED_OPTIONS > run.log 2>&1
```

코어 수·MPI 방식·노드 목록·메모리 옵션은 프로그램별로 다릅니다. 단일 노드 계산 성공 후 멀티노드 계산을 시험합니다. 여러 노드에서 같은 파일을 동시에 덮어쓰지 않도록 작업 폴더와 출력 파일을 분리합니다.

ANSYS의 경우 제품·버전·실행 경로·라이선스 서버·HPC 사용 권한·MPI/IB 설정을 설치 담당자에게 확인합니다. 클러스터의 일반 OpenMPI 모듈을 ANSYS용 MPI로 자동 지정하지 않습니다.

### 접속 종료 후에도 유지해야 하는 작업

현장에서 `tmux` 사용을 허용하고 설치한 경우의 예입니다. 프로그램을 실행할 **계산 노드**에서 시작합니다.

```bash
tmux new -s first-test
```

세션 안에서 계산을 시작합니다. `Ctrl+b`를 누른 뒤 `d`를 누르면 세션에서 분리됩니다. 같은 노드·같은 계정으로 돌아와 다시 연결합니다.

```bash
tmux attach -t first-test
```

tmux는 노드 재부팅·장애를 견디는 작업 관리자가 아니며, 현장의 로그아웃 정리 정책에 따라 유지되지 않을 수 있습니다. 긴 계산에는 프로그램의 체크포인트 기능과 승인된 실행 방식을 확인합니다.

### 진행 확인과 중지

다른 접속 세션에서도 작업이 실행되는 같은 노드·같은 경로에서 확인합니다.

```bash
tail -n 50 run.log
tail -f run.log
```

`tail -f`는 `Ctrl+c`로 종료해도 계산이 중단되지 않습니다. 계산 자체는 제품의 정상 종료·체크포인트 저장 기능을 먼저 사용합니다. 프로세스를 종료해야 하면 본인 PID와 작업을 확인한 뒤 `kill -TERM PID`를 사용합니다. MPI 작업은 여러 프로세스를 만들 수 있으므로 실행기 또는 제품이 안내한 종료 방법을 따릅니다. `killall`, 다른 사용자의 PID, 강제 종료를 일반 절차로 사용하지 않습니다.

## Slurm으로 작업 제출
Slurm을 사용하지 않는 현장은 이 절을 건너뜁니다. 파티션·제한 정책은 현장 안내서에 따릅니다.

```bash
sinfo
squeue -u "$USER"
```

첫 배치 작업은 계산하지 않는 작은 시험으로 시작합니다. 로그인 노드의 공유 작업 폴더에서 다음 파일을 만듭니다.

```bash
cat > hello.slurm <<'EOF'
#!/bin/bash
#SBATCH --job-name=hello
#SBATCH --nodes=1
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=1
#SBATCH --time=00:02:00
#SBATCH --output=hello-%j.out
hostname
date
EOF
sbatch -p YOUR_PARTITION hello.slurm
```

제출 응답의 Job ID를 기록하고 `squeue -u "$USER"`로 확인합니다. 완료 후 현재 폴더의 `hello-작업번호.out`을 확인합니다. 취소는 `scancel YOUR_JOB_ID`를 사용합니다.

`srun hostname` 같은 명령은 실행할 명령이 끝나면 종료됩니다. `srun --pty bash`로 대화형 셸을 시작한 경우 셸을 `exit`로 끝내야 합니다. 작업 목록에서 사라졌다는 것만으로 계산 성공을 판단하지 말고 출력·오류 로그와 결과를 확인합니다. `sacct`는 회계 기능이 구성된 경우에 사용합니다.
