# GUI와 선택 기능
GUI용 X11 전달은 내 PC의 X 서버·서버 설정이 모두 필요합니다. 일반 SSH 접속과 별도 기능입니다. `ssh -X`를 먼저 사용하고, 신뢰하는 서버에 한해 필요 시 `-Y` 사용 여부를 관리자에게 확인합니다. 계산 노드까지의 GUI 접속은 승인된 별도 절차를 따릅니다.

Jupyter는 X11을 필수로 요구하지 않습니다. 현장에서 허용한 실행 노드에 서버를 띄우고 SSH 로컬 포트 전달로 브라우저에서 접속할 수 있습니다. 다음은 **내 PC에서 실행 노드에 직접 SSH 접속 가능한 경우**의 예입니다.

실행 노드에서:

```bash
jupyter lab --no-browser --ip=127.0.0.1 --port=8888
```

내 PC의 별도 터미널에서:

```bash
ssh -N -L 127.0.0.1:8888:127.0.0.1:8888 -p YOUR_NODE_SSH_PORT YOUR_USER@YOUR_EXECUTION_HOST
```

내 PC 브라우저에서 `http://127.0.0.1:8888`을 열고 서버가 안내한 인증 절차를 따릅니다. 토큰은 공유하지 않습니다. 중계·Slurm 자원 배정이 필요한 현장에는 이 명령을 그대로 적용하지 말고 관리자의 터널·작업 할당 절차를 받습니다. 포트 충돌 시 양쪽 포트와 URL을 함께 조정합니다.

컨테이너는 관리자가 제공·허용한 실행기와 이미지로 사용합니다. Docker 그룹 권한은 일반적인 프로그램 실행 권한보다 강합니다. 그룹 가입을 자동 요청하거나 rootless 구성의 보안 보장을 임의로 가정하지 않습니다. Apptainer/Singularity도 호스트 경로 바인드·네트워크·GPU 접근 정책을 따릅니다.
