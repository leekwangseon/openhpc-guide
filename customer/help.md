# 문제 해결과 문의
| 증상 | 먼저 확인 | 관리자에게 보낼 정보 |
|---|---|---|
| 접속 실패 | 주소·포트·VPN·계정·호스트 키 변경 여부 | 시각, 사용한 명령, 비밀값을 지운 오류 |
| 명령을 찾을 수 없음 | 실행 노드, 프로그램 설치·module 목록 | `hostname`, `module list`, 프로그램 버전 |
| 파일 쓰기 실패 | 지정 경로, 권한, 용량·quota | `pwd`, `ls -ld .`, `df -h .` |
| 계산 실패·느려짐 | CPU·메모리·제품 로그·동시 사용 현황 | 노드, 자원 수, 로그 마지막 부분, 재현 절차 |
| 라이선스 오류 | 제품·버전, 안내받은 서버 설정 | 오류 코드, 발생 시각, 제품명. 라이선스 원문 제외 |

문의에는 실행 명령, 작업 폴더, 노드 이름, 프로그램 버전, 시작·실패 시각을 적습니다. Slurm 작업이면 Job ID도 추가합니다. 비밀번호·키·토큰·개인정보·연구 데이터는 필요 범위를 확인한 뒤 전달합니다.
